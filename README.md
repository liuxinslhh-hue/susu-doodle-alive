# 乱画成精 · Doodle Alive

随手画一个小家伙，叫醒它，再给它画点吃的。

**[打开在线试玩](https://susu-doodle-alive.paomian123.chatgpt.site/)**

这是 Susu 和 AI 一起做的互动网页实验。它还很简单，欢迎试玩、提问题，或改成自己的小玩具。

## 能玩什么

- 自己画角色，也可以从软趴趴、长耳朵、歪星星三个示例开始。
- 点角色身体会有弹性形变；按住拖动，松手后会下落反弹。
- 选择饭团、辣椒或柠檬，画出食物，喂给角色。
- 饭团会鼓肚，辣椒会喷火，柠檬会让它皱脸；尝过的口味会记进当次手账。
- 网页版可以本地导出约3秒的表情GIF。

**程序不会识别画作语义。** 食物含义由玩家先选择，任意笔迹通过同一套弹性形变获得动作。它没有图像识别、角色骨骼或运行时大模型。

## 本地运行

```sh
python3 -m http.server 5174
```

然后打开 `http://localhost:5174`。不需要构建或安装依赖。

## 实现

- 原生 HTML、CSS、Canvas 2D。
- 按透明像素裁切画作，网格映射保留笔迹，弹簧形变配合重力和碰撞。
- 进食状态与口味记录位于 `feeding.js`。
- `gif.js` 是小型定色板/LZW编码器，导出在本机完成。
- 不上传画作，没有账号系统、统计脚本、付费接口或外部资源。

## 已知限制

- 画作保存在当前浏览器，可能随浏览器清理而丢失；口味手账只记录当次角色。
- GIF是最后口味的一段统一循环动作，不是鼠标操作录像。
- 基础交互与实际GIF下载曾在Chrome验证；喂食新增流程通过代码侧检查，具体画面仍待更多浏览器验证。
- 手机宽度布局曾检查，真实手机触摸、Safari和旧版WebView未完整验证。
- 这是尚在收集反馈的原型，不声称玩法或市场需求已验证。
